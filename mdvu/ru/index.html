FAQ

Вопросы и ответы

Подробнее — в README ↗

Что такое просмотрщик Markdown?+

Просмотрщик Markdown отображает обычные MD-файлы как оформленные документы: с заголовками, таблицами, кодом и ссылками. MDVu даёт нативный просмотр Markdown на Mac и Windows, включая локальное отображение формул и диаграмм.

Какие Markdown-файлы можно открыть?+

MDVu открывает документы с расширениями .md, .markdown, .mdown и .mkd. Откройте README, документацию проекта или папку заметок прямо из Finder, Проводника или командной строки. Исходные Markdown-файлы остаются на своих местах.

MDVu — это редактор?+

MDVu создан для просмотра. Пишите в любимом редакторе, а MDVu держите рядом: при сохранении файла документ обновляется автоматически. Это инструмент для чтения, проверки и навигации по Markdown.

Какие системы поддерживаются?+

macOS 13+ на Apple Silicon и Intel; Windows 10/11 x64 с Microsoft WebView2. Для Mac выбирайте DMG, для Windows — MSI. Portable ZIP: Mac ARM, Universal, Intel и Windows x64. Пакеты Windows выпускаются начиная с 0.5.0.

Он действительно работает офлайн?+

Markdown, формулы и встроенные движки диаграмм работают локально, без сервера, аккаунта и установки Java. Внешние изображения и другие удалённые ресурсы самого документа могут обращаться к сети. В MDVu нет телеметрии.

Можно открыть хранилище Obsidian?+

Да. Откройте папку или Markdown-файл внутри хранилища. MDVu распознаёт корни .obsidian и .git, поддерживает выноски, вики-ссылки и медиа-вставки. Плагины Obsidian не запускаются; полного повторения всех его возможностей нет.

Почему macOS может показать предупреждение при запуске?+

Текущие сборки macOS подписаны ad-hoc, без нотариализации Apple. Gatekeeper может потребовать отдельного разрешения при первом запуске. Скачивайте приложение из официальных релизов, проверяйте опубликованную SHA-256-сумму и следуйте инструкции по установке ниже.

Можно использовать бесплатно в работе?+

Да. MDVu распространяется под лицензией MIT, без подписки и платных уровней функций. Встроенные сторонние компоненты сохраняют собственные лицензии, перечисленные в репозитории.
