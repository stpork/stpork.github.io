Method and scope

Cold and warm starts

Same Mac, one document per fresh process. First readable body comes from system frames before any input; the Mermaid control requires the visible graph. RAM: median at 8 s / peak in the first 8 s, including helper processes. Application caches are cleared for cold starts; the OS file cache remains. Warm starts follow a complete cold traversal. First valid complete pair per file; later repeats remain in raw data.

Verified full-document passes: 135 / 192. Frame intervals are shown when the capture cannot support a precise point value. Full traversal checks EOF, not rendering speed or automatic success of every diagram. Earlier calibration attempts are excluded.

† Startup timing and first-8-s RAM are qualified independently; later traversal was not confirmed by the input adapter. The paired cold pass completed. The later observed peak is not a full-file memory result.
