FAQ

Questions and answers

More details in the README ↗

Which version is available?+

Download buttons always fetch the latest stable release. Install it with the macOS DMG or Windows MSI, or choose portable ZIPs on GitHub Releases.

What makes a Markdown viewer feel blazing fast?+

Ultra-fast Markdown parsing comes from a shared Rust core. Native windows and diagram engines loaded only when needed keep the app supercompact. Cached SVGs speed up repeated opening; the comparison reports recorded size, memory and first-render times.

Why choose an ultra-small Markdown viewer?+

A lightweight viewer opens your documents without a full editor or note-taking workspace. MDVu uses the system WebKit or WebView2 engine and compressed diagram libraries for an ultra-compact app with built-in Markdown, math and diagrams.

What is a Markdown viewer?+

A Markdown viewer, also called an MD viewer, displays plain .md files as formatted documents, with readable headings, tables, code and links. MDVu provides a native Markdown preview on Mac and Windows, including offline math and diagram rendering.

Which Markdown files can I open?+

MDVu is an MD file viewer for .md, .markdown, .mdown and .mkd documents. Open a README, project documentation or a folder of notes directly from Finder, Explorer or the command line. The original Markdown files stay where they are.

Can I use MDVu as a live Markdown view?+

MDVu is a dedicated viewer, not an editor. Write in your favorite editor and keep a live Markdown view beside it: saving the file refreshes the preview. Read, review and navigate without changing your workflow.

Which systems are supported?+

macOS 13+ on Apple Silicon and Intel; Windows 10/11 x64 with the Microsoft WebView2 runtime. Use DMG for Mac or MSI for Windows. Portable ZIPs cover Mac ARM, Universal, Intel and Windows x64. Windows distribution starts with 0.5.0.

Does it really work offline?+

Markdown, math and the bundled diagram engines render locally without a server, account or Java installation. Remote images or other external resources referenced by a document can still use the network. MDVu itself has no telemetry.

Can I open my Obsidian vault?+

Yes. Open a folder or a Markdown file inside your vault. MDVu recognizes .obsidian and .git roots and supports callouts, wikilinks and media embeds. It does not run Obsidian plugins or replicate every vault feature.

Why might macOS show a first-launch warning?+

Current macOS builds use ad-hoc signing, without Apple notarization. Gatekeeper may ask for an explicit first-launch approval. Download only from the project’s official releases, check the published SHA-256 checksum and follow the installation notes linked below.

Is it free for commercial use?+

Yes. MDVu is released under the MIT license, with no subscription or paid feature tier. Bundled third-party components retain their own licenses, listed in the repository.
